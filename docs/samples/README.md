# Sample reports (simulated data)

Every file in this folder was generated by `python scripts/generate_sample_reports.py` from
**simulated data only**, in a throw-away database:

- a fictional vehicle ("Sample vehicle (fictional)", no VIN or registration);
- one 7-minute simulated drive with the *engine overheating* scenario, analysed by the real
  hybrid diagnostic engine and shipped models;
- one trouble-code scan from the **mock** OBD-II adapter (its codes are simulated);
- two maintenance records and two schedules entered as examples (one uses an example interval,
  labelled as such);
- two sample notifications.

Nothing here comes from a real vehicle, and the findings shown are not diagnoses.

| File | Report |
|---|---|
| `sample-vehicle-diagnostic.pdf` | Vehicle diagnostic report |
| `sample-ai-assessment.pdf` | AI diagnostic assessment report |
| `sample-trouble-codes.pdf` | Diagnostic trouble code report |
| `sample-trip.pdf` | Trip report |
| `sample-maintenance.pdf` | Vehicle maintenance history report |
| `sample-vehicle-overview.pdf` | Comprehensive vehicle overview |
| `sample-model-evaluation.pdf` | Model evaluation report (synthetic test data) |
| `sample-*.csv` | One file per CSV dataset (telemetry, trips, findings, trouble codes, health, maintenance, notifications, model evaluation) |
